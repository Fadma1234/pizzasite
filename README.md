### Recipe Hub

<img width="848"  alt="image" src="https://github.com/user-attachments/assets/c36c6069-476c-4611-8af2-aaed7492ca7c" />

This project is the server-side architecture for a full-stack web application, utilizing Node.js with the Express.js framework to create a robust, authenticated web service. The application leverages several key middleware packages: Morgan for logging, Body-Parser for handling form data, Cookie-Parser and Express-Session for managing user sessions, and Connect-Flash for displaying ephemeral status messages. Crucially, the system integrates Passport.js for comprehensive local user authentication (login/signup functionality), storing user data securely in a MongoDB database managed via Mongoose ODM. Once the Mongoose connection to the database is established, the application initializes and loads a separate routes definition file, ensuring all backend functionality and secure endpoints are available and listening on a defined port (default 8080).
